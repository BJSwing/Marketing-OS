Who does the work

Nine agents

An agent is a module that decides and acts on its own. Every agent runs on the same brain and reads the same brand files. Each one has a narrow job and only the permissions that job needs.

Privilege separation

Who can do what

No agent can spend money. Spending always goes through your approval queue. Only the Publisher, Email and Community agents can send anything to the public.

Not agents

What the agents use

These modules don't make decisions. They hold data, supply tools or keep you in control.

Tools and data

Signals, System of Record, Data & Observability. Agents read from and write to these.

The Brain

The shared engine every agent runs on: the model, memory, image and voice tools. It is not an agent itself.

You and the control plane

Brand files, budget cap, approval queue, activity log and kill switch. Rules, not reasoning.

What interrupts the loop

Eight events, one rule each

Each event used to need a marketer at a desk. Here a watcher spots it, a department handles it, and you only hear about it when money or judgment is involved.

Build one phase at a time. Each phase is usable on its own, so you get value before the whole system exists.
